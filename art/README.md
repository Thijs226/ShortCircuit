# Short Circuit custom game artwork

Generated specifically for this update with the built-in image generation tool. The unmodified generated RGBA atlas is `maze-atlas-original.png`. The app uses the same artwork encoded as WebP in `res/drawable-nodpi/maze_atlas.webp`; transparency and the 1536 by 1024 resolution are retained. There are no generated pipe connections: exact channels and win paths are drawn from the maze model.

The six sprites are polished oak, blue metal start, gold metal goal, dark recessed empty space, aqua glass marble and walnut board frame. MazeArt.java maps their source rectangles into the renderer.

## Channel update in 1.3

MazeChannel.java draws wider recessed paths with smoothly blended walls, a fine lower highlight and material-specific colors. Paths are clipped to the tile bounds so open ends do not protrude into empty spaces. The ball's displayed diameter is 32 percent of a tile and fits within the 42.4 percent channel. The existing midpoint curves and exact connections are retained, so appearance and the rolling animation agree.

`channel-preview-v1.3.jpg` is a desktop vector-rendering comparison made on the build VPS using the production MazeChannel class and a minimal Java2D adapter. It shows all six two-way path shapes, fixed endpoints, connected paths and small Demon tiles. It is a visual inspection aid, not an Android screenshot or a device-performance test.
